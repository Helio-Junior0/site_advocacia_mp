# Maria Paula Advocacia — Site Institucional

Site institucional da **Dra. Maria Paula**, advogada inscrita na OAB/MT, com atendimento em Poconé-MT e região do Pantanal.

---

## Sobre o Projeto

Site desenvolvido para apresentar os serviços jurídicos da Dra. Maria Paula, proporcionando uma experiência profissional, elegante e acessível ao cliente.

---

## Estrutura de Arquivos

```
SITE ADVOCACIAMP/
├── index.html       # Estrutura principal do site
├── style.css        # Estilos e layout visual
├── script.js        # Interatividade e animações
└── img/
    ├── advgada.jpeg # Foto da advogada (seção Sobre)
    └── logo.png     # Logotipo MP (header, footer e favicon)
```

## Seções do Site

| Seção | Descrição |
|---|---|
| **Hero** | Apresentação do escritório com chamada para agendamento |
| **Números** | Estatísticas: 5+ anos, 600+ casos, 500+ processos |
| **Sobre** | Perfil da Dra. Maria Paula, valores e filosofia de trabalho |
| **Áreas de Atuação** | Direito Previdenciário, Trabalhista, do Consumidor e de Sucessão |
| **Contato** | Formulário de contato + endereço, telefone e e-mail |
| **Rodapé** | Links de navegação e informações do escritório |

---

## Funcionalidades

- Menu responsivo com hambúrguer para mobile
- Scroll suave entre seções
- Animações de entrada (fade-up) com IntersectionObserver
- Contador animado nos números do escritório
- Máscara automática no campo de telefone
- Validação de formulário de contato
- Botão flutuante de WhatsApp
- Header com efeito ao rolar a página

---

## Tecnologias Utilizadas

- **HTML5** — semântico e acessível (WAI-ARIA)
- **CSS3** — variáveis CSS, Flexbox, Grid, animações
- **JavaScript** — vanilla JS (sem frameworks ou bibliotecas externas)
- **Google Fonts** — Cormorant Garamond + Inter
